# Presento 🎤

Plateforme interactive de présentations et sondages en direct (alternative moderne et réactive à Mentimeter).

## 🚀 Fonctionnalités
- **Questions interactives** : Choix multiples, nuages de mots, questions ouvertes, notation / évaluations, quiz avec bonne réponse.
- **Pages de texte modulables** : Titres, sous-titres, paragraphes, points clés et citations avec réorganisation par glisser-déposer.
- **Visualisations multiples** : Colonnes, barres horizontales, donut, cartes, mur d'idées, bulles flottantes, etc.
- **Sécurité animateur & Participants instantanés** : Code PIN à 6 lettres et QR code dynamique.
- **Backend réactif Convex** : Capacité de 1 000 participants connectés en direct sans latence.

## 🛠️ Démarrage local

```bash
npm install
npm run dev          # Serveur Vite frontend (http://localhost:5173)
npm run convex:dev   # Backend local réactif Convex (http://127.0.0.1:3210)
```
